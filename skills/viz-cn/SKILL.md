# 最小化图示

一张图只有在替代文字时才值得画：能用一句话说清的不画；一张图只表达一个关系或一个过程；元素不超过七个左右，对象本身超过限额时拆成多张（如 TCP 状态机分「建立」与「释放」两张）或只画主路径并在说明里注明省略了什么；不加装饰、不加与理解无关的颜色。图内文字用中文，术语可附英文。

## 路径约定

`attachments/`、`sessions/` 相对当前工作目录（学习目录）；`references/…` 相对本技能目录。不在技能目录内创建或修改任何文件。开始前用 `bash` 执行 `date +%F` 与 `date +%H:%M` 取得日期与时刻。

## 选型

- **mermaid**：概念之间的依赖、包含与流程（`graph TD` 或 `graph LR`）、状态机（`stateDiagram-v2`）、交互时序（`sequenceDiagram`）、时间线（`timeline`）。Obsidian 原生渲染，直接以 ```mermaid 代码块嵌入笔记，一般不落文件（独立调用且无会话文件时例外，见「嵌入位置」）。
- **SVG**：需要坐标或几何（向量、曲线、切平面、投影）、数据结构的内存布局、数值比例。写入 `attachments/<slug>-<对象>-<序号>.svg`：slug 取当日会话文件名中的 slug，无会话文件时按通行英文名或拼音临时取一个；`<对象>` 用短横线连接的小写 ASCII（`covector-on-vector`），不含空格与中文。在笔记里用 `![[attachments/<文件名>]]` 嵌入。规则见 `references/svg.md`。
- **等宽字符图**：一维布局（字节序、栈帧、字符串索引）用代码块里的字符图即可，不必 SVG。

## mermaid 规则

节点 id 一律用 ASCII；标签一律加双引号；标签内不写半角的 `[`、`]`、`(`、`)`、`{`、`}`、`|`、`$`、`;`、`#` 与 `"`（方括号与圆括号是节点形状语法，分号在 `sequenceDiagram` 与 `stateDiagram-v2` 中是语句分隔符，井号是实体码前缀，引号与标签定界冲突；标签内不渲染 LaTeX），需要这些符号时改用全角「；（）」与弯引号「“”」；每个节点只定义一次，其余边用裸 id；`graph` 中 `subgraph` 不嵌套超过一层。`sequenceDiagram` 的参与者用 `participant A as 显示名` 声明，`as` 后直接写显示名，不加引号；`stateDiagram-v2` 的状态名用 ASCII 并以 `state "显示名" as s1` 声明中文显示名。生成后逐行对照上述规则自检。

## 嵌入位置

- **教学进行中**（由 `teach-cn` 调用）：图放在当前节点「正式内容」之后、「逐句拆解」之前，随节点内容一起写入会话文件。终端不渲染 mermaid，且节点通过检验前会话文件里还没有它：讲解当场需要学习者看图时选 SVG，写入 `attachments/` 后立即在对话里给出路径请其在 Obsidian 打开；mermaid 只用于事后回看即可的图，并在对话里说明它将随节点写入会话文件。
- **独立调用**：先在对话里给出一句说明与图的去处（mermaid 给源码；SVG 只给路径，不把 XML 贴进对话）。若今日存在教学会话文件（`ls sessions`，取文件名为 `<今日>-<slug>.md` 且不含 `-quiz` 者；多份时按对象所属主题选择，无法判断则问一句），把「图示 HH:MM · <对象>」一行与图（或嵌入链接）插入「支线待办」节末尾：以 `## 小结` 这一行为 `edit` 的 oldText，newText 为「图示内容 + 空行 + `## 小结`」。不存在会话文件时：SVG 只写入 `attachments/` 并告知路径；mermaid 写入 `attachments/<slug>-<对象>-<序号>.md`（内容仅一个 ```mermaid 代码块，Obsidian 可直接打开，日后可用 `![[attachments/<文件名>]]` 嵌入）并告知路径；不新建会话文件。

## 自检与确认

mermaid：逐字符对照规则；不确定的语法宁可退回最简单的 `graph TD`。SVG：用 `read` 重读源码做源码级检查（坐标是否都在 `viewBox` 内、文本包围盒是否重叠、箭头端点方向是否与说明一致）；pi 的 `read` 不渲染 SVG，你看到的是 XML 源码，不要声称「看到了图」。视觉效果请学习者在 Obsidian 中确认；学习者说有问题时按其描述修改，不猜。

## 语言与风格

书面正式语体，中文全角标点。不使用感叹号、emoji 与鼓励性套话。图的说明只写一句：这张图表达的是什么关系。
