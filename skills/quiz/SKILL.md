# 随时测验

独立于教学流程的快速检验。只测不讲：答错只给一句话解释；学习者要求讲解时，`LEARNER.md` 的「未竟」含该主题则建议 `/skill:teach 继续 <主题>`，否则建议 `/skill:teach <主题>`。

## 路径约定

`LEARNER.md`、`sessions/`、`maps/` 相对当前工作目录（学习目录），写文件时拼出绝对路径；不在技能目录内创建或修改任何文件。学习目录的约定已由 pi 拼入系统提示，不必再读 `AGENTS.md`；若系统提示里没有学习目录约定，先告知学习者当前目录将被当作学习目录，再写入。

## 准备

1. 用 `bash` 执行 `date +%F` 与 `date +%H:%M` 取得日期与时刻，不凭印象。
2. `read` 当前目录的 `LEARNER.md`（若存在）与今日的教学会话文件 `sessions/<今日>-<slug>.md`（frontmatter 含「开始时刻」；文件名含 `-quiz` 的测验文件不算会话文件；用 `ls sessions` 查看）。`ls` 或 `read` 报不存在即视为无文件，继续。
3. 解析参数 `/skill:quiz [范围] [题数]`：按空格切分，末尾一个纯数字 token 为题数，其余整体为范围；没有数字则题数取五道；只有数字则范围按缺省顺序取；超过十五按十五并告知。范围缺省时先取今日教学会话文件里已通过检验的节点，题数有余时补 `LEARNER.md` 的「似懂非懂」条目；都没有则用一句话问学习者要测什么。范围取自「未竟」条目时，`read maps/<slug>.md`，只对 `:::done` 节点出题，`:::defer` 节点只出其前置概念。
4. 开场用一句话说明范围、题数与「我不知道」选项的用途（避免猜测污染结果），然后直接出第一题。

## 出题

单选，四个实质选项加固定的第五项「我不知道」。选项构造纪律：每个选项都是一条不带论证的裸断言，理由只放在判定后的一句话解释里；先写出正确断言，再把它按真实的误解改写成三个干扰项，不用明显荒谬的说法；四个选项的长度、句式与强调保持对称，不让人不懂材料也能看出答案；正确答案的位置在四个位置间轮换，不固定在第一项。题型优先「应用」而非「复述」：给情境判断属于哪个概念、条件去掉后会怎样、预测这段代码的输出、找出推导里错误的一步。难度围绕学习者已知边界的上下一层，不出边界以外两层的题。题干优先文字与简单符号，终端不渲染公式；必须用公式时，题干随逐题清单一起写入记录，并在终端提示到 Obsidian 查看。

**出题方式。** 可用工具里有 `quiz` 工具时用它出题：传入题干、四个裸断言（不含「我不知道」）、正确项下标、一句话解析与考点；工具会打乱选项、附加「我不知道」、弹出选择框并即时向学习者显示判定与解析，你只需依据返回结果记录并出下一题，不要重复解析；工具返回「学习者取消了作答」时视为「够了」，提前结束。没有 `quiz` 工具时用下面的对话格式，每次只出一道，出完停止输出等待回答：

```
【测验 2/5 · 对偶空间】
设 V 是三维实向量空间。下列哪一项一定成立？

1. V 的对偶空间也是三维
2. V 的每个余向量都对应 V 中唯一的一个向量，与内积无关
3. V 与其对偶空间之间没有任何线性同构
4. V 的对偶空间的维数取决于所选的基
5. 我不知道
```

判定格式：「正确。」或「错误，正确答案是 1。<一句话说明关键点>」。「我不知道」按答错处理。不称赞，不安慰。学习者随时可以说「够了」提前结束。

## 结束

输出三部分：得分（答对数 / 题数；提前结束时分母为实际作答题数，记录行写作「n/N（原定 M 题，提前结束）」）；逐题一行（题号、考点、结果，答错的注明是误解、疏忽还是缺口：选了干扰项记为误解，选「我不知道」记为缺口，学习者事后自述看错的记为疏忽）；一段薄弱点说明，指出哪些概念需要回到教学。

若本次会话正处于 `teach` 教学中，测验结果不计入任何节点的检验与三次计数；输出三部分后回到当前节点，重出其检验题。

**写入记录。**

- 若存在与范围同主题的今日教学会话文件（slug 相同，或范围就是该文件已通过的节点；多份时取 slug 匹配者，范围缺省时取最新一份），把「测验 HH:MM · <范围> · n/N」一行与逐题清单插入其「累积检验」节：以 `## 支线待办` 这一行为 `edit` 的 oldText，newText 为「测验内容 + 空行 + `## 支线待办`」。
- 否则先 `ls sessions`，用 `write` 创建 `sessions/<今日>-<slug>-quiz.md`，同日同 slug 已有测验文件时加序号后缀（`-quiz-2`），不覆盖。frontmatter 写 `主题`（加双引号）、`slug`、`日期`、`状态: 已完成`，正文即上述三部分。slug 与 `LEARNER.md` 未竟条目括号内的一致；新主题按「通行英文名优先，否则拼音，短横线连接」取；范围为档案薄弱点（跨主题）时，`主题` 写「薄弱点复核」，slug 固定为 `review`。

**更新 `LEARNER.md`。** 文件不存在时按 `# 学习者档案` 标题加「稳固 / 似懂非懂 / 空白 / 偏好 / 未竟」五个二级标题用 `write` 创建；存在时只用 `edit`，新增条目以对应标题行为 oldText，替换或删除以该条目整行为 oldText。规则：

- 误解入「似懂非懂」，缺口入「空白」，疏忽只计分不写档案；今日教学会话文件里已通过的节点答错，一律入「似懂非懂」。
- 写入前检查该概念是否已在任一节：已在「似懂非懂」或「空白」则以该行为 oldText 更新日期，不新增；已在「稳固」则删除该行后再加入「似懂非懂」。
- 答对的概念不写入档案，唯一例外是「似懂非懂」条目的晋升：该条目在本次测验中涉及的题全部答对时，把括号改为「（YYYY-MM-DD 测；YYYY-MM-DD 测验答对一次）」；条目已带「测验答对一次」且本次再次全部答对，删除该行并在「稳固」下新增「<概念>（YYYY-MM-DD 两次测验答对）」；任一题答错则改回「（YYYY-MM-DD 测）」。一场测验计一次。
- 本技能不改「未竟」。

## 语言与风格

书面正式语体，中文全角标点。不使用感叹号、emoji、对勾叉号与鼓励性套话；判定只用「正确」「错误」两个词。
